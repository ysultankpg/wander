What it does

Tell it your season, budget, and what you actually enjoy. It shortlists real destinations, checks live conditions, and builds a grounded day-by-day plan — inventing nothing.

🌦️

Live weather & time

Current conditions and a short forecast for anywhere on earth, plus correct local time via IANA timezones — from Open-Meteo, keyless.

💱

Real exchange rates

Budget conversions computed against the European Central Bank's daily reference rates via Frankfurter — never estimated in the model's head.

📍

Real places

Temples, cafés, viewpoints and museums pulled from OpenStreetMap's Overpass API — actual named features, not plausible-sounding fabrications.

📸

Real photographs

Destination imagery from Wikimedia Commons. When no photo exists it says so, rather than faking a broken file.

🧠

Remembers you

Diet, allergies, budget ceilings and travel style persist in SQLite across sessions — and are checked before any food recommendation.

🛡️

Grounded by design

Strict rules forbid inventing prices, hours or flights. Tool failures are shown honestly instead of being papered over with a guess.

How a turn works

A bounded tool-calling loop: the model plans, calls real tools, and only then writes the answer.

Understand

The local model reads your request alongside what it already knows about you from SQLite memory.

Call tools

It requests weather, time, FX, places or catalog lookups. They run concurrently against the live keyless APIs.

Ground

Results — or honest errors — feed back in. Nothing is invented; an empty result never becomes a fabricated one.

Answer

The reply streams to the browser token by token over SSE, with tables, real photos and a grounded plan.

Run it locally

Three commands to get the model, three to serve the app. Everything stays on your machine.

# 1 — install and start the local model
brew install ollama
brew services start ollama
ollama pull llama3.1:8b

# 2 — set up and serve Wander
cd wander
uv venv --python 3.11
uv pip install --python .venv/bin/python fastapi "uvicorn[standard]" httpx itsdangerous
./run.sh

Then open http://localhost:8000 — the chat interface is served at the root URL. This showcase page is static; the live agent needs the local server, Ollama and SQLite, which is why it can't be hosted here on GitHub Pages.
